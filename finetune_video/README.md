# Fine-tuning Qwen VLMs to read DxR charts from Quest videos

Training uses only synthetic charts generated by `make_video_dataset.py --strict` (made-up names and values, real
chart names excluded). The real Quest recordings are test inputs only; the ground-truth tables are read only by the
scorer, after the model has answered.

| File | What it does |
|---|---|
| `make_video_dataset.py` | synthetic 8-frame walk-around clips + exact CSV answers; `--strict`, `--charts`, `--size` |
| `sample_real_videos.py` | Quest videos -> 8-frame test clips in `real_clips/` (test only) |
| `train_video_lora.py` | Unsloth LoRA (rank 16, vision + language) on Qwen3.5-9B, 8 frames per example |
| `eval_video.py` | evaluate a model on real videos (+ synthetic val clips); `--compare` table |
| `eval_median.py` | median of 7-frame votes + offset learnt on synthetic clips only |
| `vscore.py` | scoring fallback for `vlm_eval/score_tables.py` (line-chart curve scoring) |
| `../notebooks/Run4_line_colab.ipynb`, `Run4_line_kaggle.ipynb` | end-to-end runs (Colab A100/T4, Kaggle T4) |

## Line chart results (real Quest video `line_clear`, 48 Gapminder values)

| Model | Within 5 % | Within 2 % | Mean error |
|---|---|---|---|
| Qwen3.5-9B untrained | 50 % | 11/48 | 7.43 % |
| Run 3: LoRA, 1,000 clips, 640 px | 97.9 % | 35/48 | 1.68 % |
